# slh-verify-m2d — M2d full SLH-DSA-SHAKE-128s verification composition

M2a/M2b closed the WOTS+ chains and M2c the tree-side mechanisms; this crate
composes them into **full signature verification** of real
SLH-DSA-SHAKE-128s signatures produced by the `fips205` reference crate.

## Integration method (the M2d selection)

Not one monolithic trace, but **15 proofs glued by public interface
values** — the shape that feeds directly into M3 aggregation and the M0.5
recursion/wrap track:

| Proof | Content | AIR |
|-------|---------|-----|
| A | H_msg + 14 FORS trees (leaf + 12 climbs each) + T_k (186 slots) | generalized pipeline (`pipeline.rs`) |
| chain L0..L6 | per-layer WOTS+ digit-driven chains | M2b AIR, ported unchanged (`chains/air.rs`) |
| tree L0..L6 | per-layer T_len (5 blocks) + XMSS auth path (14 slots) | generalized pipeline |

Claimed interface values — the H_msg digest, 14 FORS roots, FORS pk, and
per-layer WOTS+ pk elements and XMSS roots — are each **bound by their
producing proof** and **natively derived into their consumers'** public
inputs (digits from the claimed FORS pk / previous root, ADRS tables from
the claimed digest, T_k and T_len blocks from the claimed roots / pk
elements). The final native check is `root == PK.root`. A forged claim at
any interface makes its producing proof reject; a tampered signature or
message keeps every proof honest but moves the final root — exactly the
soundness chain of native SLH-DSA verification.

`pipeline.rs` generalizes the M2c machinery (slot walk, public rate tables,
mask/chain value pairs, XOR-linked multi-block absorption over committed
output bits, capacity carry) to arbitrary slot configurations and output
binding widths (the 30-byte H_msg digest binds 15 limbs).

## Conformance

Signatures are generated by `fips205` (keygen + sign); `refimpl.rs`
recomputes every intermediate with `sha3` and the recomputed hypertree root
must equal PK.root. This end-to-end equality validates the FIPS 205
structural interpretation (H_msg framing incl. the pure-signing 0x00‖len(ctx)
prefix, FORS index extraction, ADRS layouts, base-w digits, T ordering)
before any proof is even produced — and proof acceptance then shows the
constraint stack accepts exactly that structure.

## Run

```bash
cargo run --release
```

- 2 honest full verifications (keygen/sign via fips205): all 15 proofs must
  accept, recomputed root must equal PK.root; per-proof and total
  prove/verify times are printed (NFR-3 evidence).
- Forged-claim battery: honest proofs re-verified against public inputs
  derived from forged claims (digest, FORS root, FORS pk, WOTS pk element,
  layer root) — all must reject.
- Input-tamper battery: tampered signature bytes (FORS sk, WOTS element, R)
  and a wrong PK.root — rejected by the final native root comparison.

FRI parameters match M0..M2c (log_blowup=3, 100 queries, 16-bit PoW,
single-threaded).

Results feed `docs/core/STARK_AIR_GAP_ANALYSIS.md` §11.
